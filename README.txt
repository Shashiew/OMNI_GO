OMNI-GO — ABOUT & QUICK START
=============================

WHAT IS OMNI-GO?
OMNI-GO is a personal productivity and life-management desktop app. It brings everyday planning tools into one place, including:

- Tasks, reminders and habits
- Timetable and attendance tracking
- Study timer and calculator
- Notes, exams and syllabus planning
- Library for personal reference files
- Gym/workout planning and activity logs
- Anime, movies, games and personal expense tracking
- Weather for a location you enter, when internet access is available

GETTING STARTED
1. Download the OMNI-GO ZIP file.
2. Right-click the ZIP and choose Extract All.
3. Open the extracted folder.
4. Keep OMNI-GO.exe and the entire "internal" folder together in the same folder.
5. Double-click OMNI-GO.exe to launch the app.

Do not move OMNI-GO.exe out of its folder or delete the "internal" folder. The app needs its supporting files.

YOUR DATA
OMNI-GO is intended for personal use. Workspace data is stored locally on the computer used to run the app. It is not automatically shared with other users or synced between computers. Keep backups of information you care about. If you uninstall or remove app data, you may lose saved information.

INTERNET AND WINDOWS WARNINGS
Some features, such as weather, require an internet connection. Reminder alarms and system-tray behavior depend on the app running and on Windows configuration.

If Windows displays a security warning, do not disable antivirus protection or bypass a warning blindly. Only run software you trust, and scan the downloaded ZIP with Windows Security before opening it. This app may not have a digitally signed publisher certificate.
